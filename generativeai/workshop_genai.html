Text to Image

Text → Image

Type a text prompt and FLUX will generate an image in seconds.

Estimated time: ~5 seconds

How it works

FLUX by Black Forest Labs is a state-of-the-art text-to-image model. It uses a flow matching approach (an evolution of diffusion models) to generate high-quality images from text descriptions. The schnell variant is optimised for speed — generating images in just 1–4 steps.

Image to Image

Image → Image

Upload an image and describe how you want it transformed.

Estimated time: ~10–15 seconds

How it works

FLUX img2img takes your uploaded image and uses it as a starting point instead of random noise. The denoising slider controls how much the original is changed.

Image to Text

Image → Text

Upload any image and a vision-language model will describe what it sees.

Estimated time: ~5–10 seconds

How it works

BLIP combines a Vision Transformer with a language model to generate text captions from images. Trained on millions of image-caption pairs.

PhotoMaker

Face → Character

Upload a photo of a face, then describe a scene. The model generates new images of that person in any context.

Estimated time: ~15–30 seconds

How it works

PhotoMaker by TencentARC extracts identity features from your face photo and injects them into the generation process, creating consistent characters in new scenes.

Image to 3D

Image → 3D Model

Upload an image of an object and generate a textured 3D model you can rotate and inspect.

Estimated time: ~2–4 minutes

How it works

Hunyuan3D-2 by Tencent converts a 2D image into a 3D mesh using large-scale diffusion. The result is a production-ready GLB file.

Text to 3D

Text → 3D Model

Describe an object and the model will generate a 3D shape you can rotate and explore.

Estimated time: ~1–2 minutes

How it works

Shap-E by OpenAI generates 3D implicit functions from text descriptions, producing neural radiance fields converted into textured meshes.
